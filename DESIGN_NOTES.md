# Дизайн «Фрозен Рекордс»

Обновление от 21 сентября 2026 года. Основа: [apple-design](https://github.com/dickwu/apple-design-skill/blob/main/SKILL.md). Инструкции скилла прочитаны непосредственно из репозитория; глобальная установка не выполнялась.

## Задача

Помочь артисту выбрать специалиста и время записи. Главный визуальный образ — собственный объёмный логотип студии на чистом чёрном фоне. Навигация и карточки спокойнее заставки. Цветовая гамма, локальные шрифты, фотографии и фирменный знак сохранены.

Для веб-сайта применены принципы композиции, доступности и иерархии. Нативные правила навигации iOS/macOS не переносились. По запросу владельца оставлена постоянная тёмная палитра, без переключателя темы и светлой версии.

## Система оформления

| Роль | Значение | Проверка |
|---|---|---|
| Основной фон | `#000000` | Совпадает с фоном логотипа |
| Поверхность карточек | `#10151e` | Отделяет содержание без свечения |
| Основной текст | `#e9eef7` | Контраст 15,71:1 на карточке |
| Второстепенный текст | `#a6b4ca` | Контраст 8,71:1 на карточке |
| Основное действие | `#1258de` | Белый текст — 6,04:1 |
| Ледяной акцент | `#bfe0ff` | Фирменная типографика |

Контраст рассчитан по sRGB-значениям. При наведении синий фон кнопки `#1764e8` даёт 5,22:1 с белым текстом. Граница полей `#65748b` на `#10151e` — 3,85:1.

Типографика: Unbounded для названия студии, Inter для заголовков разделов, карточек, текста и управления. Основной текст 16–20 px при стандартном размере браузера, вспомогательный обычно 14–15 px. Заголовки разделов 32–60 px. Используются rem и адаптивные размеры.

Широкий экран:

```text
                 логотип на чёрном
название и навигация ·················· запись
название студии / описание / действия
режим работы      адрес          цена от
специалисты и цены
[ специалист / услуги ] [ специалист / услуги ]
[ подробнее / запись  ] [ подробнее / запись  ]
фотографии / о студии / маршрут / контакты
```

Узкий экран:

```text
       логотип на чёрном
название        запись   меню
описание и действия
факты о студии
специалист
услуги и цены
раскрываемые подробности
запись
следующий специалист
```

Нумерация специалистов удалена: это не последовательность и не рейтинг. Цены остаются видны, биография раскрывается стандартным `details`. Добавлены переносы длинных слов. Меню работает с клавиатуры, закрывается по Escape и возвращает фокус на кнопку.

Новых декоративных анимаций нет. Сохранён переход от заставки; при `prefers-reduced-motion` логотип не растворяется. При запросе уменьшенной прозрачности шапка непрозрачна. Стили публичного интерфейса ограничены классом `public-site`, чтобы не переделывать админку.

## Применённые разделы скилла

Ссылки ниже ведут на прочитанные разделы справочника скилла, содержащие ссылки на первоисточники Apple:

- [Layout — Visual hierarchy и Adaptability](https://github.com/dickwu/apple-design-skill/blob/main/references/hig/layout.md): группировка, приоритет основной информации и адаптивность.

- [Color — Inclusive color](https://github.com/dickwu/apple-design-skill/blob/main/references/hig/color.md): контраст и дополнительные признаки выбранного состояния.
- [Accessibility — Vision](https://github.com/dickwu/apple-design-skill/blob/main/references/hig/accessibility.md): масштабирование и различимость элементов.
- [Buttons — Role](https://github.com/dickwu/apple-design-skill/blob/main/references/hig/buttons.md): заметность основного действия.
- [Dark Mode — Dark Mode colors](https://github.com/dickwu/apple-design-skill/blob/main/references/hig/dark-mode.md): проверка контраста на тёмных поверхностях.
- [Motion — Best practices](https://github.com/dickwu/apple-design-skill/blob/main/references/hig/motion.md): сдержанное и отключаемое движение.
- [Entering data — Best practices](https://github.com/dickwu/apple-design-skill/blob/main/references/hig/entering-data.md): понятные подписи и сохранение удобного ввода.

Визуальные решения для самой студии — проектные решения, а не требование Apple и не заявление о полной сертификации доступности.

## Проверено

- PHP-синтаксис изменённых шаблонов на серверном PHP 8.2; синтаксис JavaScript через `node --check`.
- Предпросмотр на ширинах 320, 360, 768 и 1440 px.
- На 320 px после исправлений нет горизонтального переполнения страницы и содержимого карточек.
- Раскрытие мобильного меню, закрытие Escape, раскрытие биографии.
- На отдельном локальном предпросмотре с искусственными слотами: выбор двух часов, выбор времени, ввод номера с автоматическим `+7`; согласие по умолчанию выключено, отправка без него недоступна.
- Контраст ключевых сочетаний рассчитан численно.

Боевые заявки при проверке не создавались. Полный аудит скринридером, увеличение текста до 200% и проверка на физических телефонах не проводились. Локальный предпросмотр формы не заменяет серверные регрессионные тесты бронирования.

## Сохранение и возврат

Исходная версия: коммит `6db63ab`, метка **`backup/pre-apple-design-2026-09-21`**. Ветка обновления: **`codex/apple-design-refresh`**.

Сначала просмотреть разницу:

```bash
git diff backup/pre-apple-design-2026-09-21 -- public_html
```

Для отката готовить отдельный обратный коммит или восстанавливать только затронутые файлы после проверки незавершённых изменений. Не применять бездумно `reset --hard`. Git хранит код; `.env` и рабочая база должны оставаться нетронутыми.
